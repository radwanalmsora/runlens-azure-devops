# Changelog

All notable changes are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses
[Semantic Versioning](https://semver.org/).

## [1.0.1] - 2026-10-30

### Changed
- Published as a public extension on the Visual Studio Marketplace.
- Added SECURITY.md and the design notes (docs/DESIGN.md) to the package.
- README now covers installation, documentation links, support, and the maintenance commitment.

## [1.0.0] - 2026-10-30

### Added
- RunLens build results tab with a failure analysis section and a performance section.
- Rule-based failure categories: environment, dependency, code, and unknown.
- Comparison with up to five recent completed builds of the same pipeline definition.
- Build-level and task-level regression detection with explicit thresholds.
- Light and dark themes that follow the Azure DevOps theme.
